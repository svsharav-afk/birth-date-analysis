# История изменений

## 1.0.0 — 3 октября 2026

### Добавлено

- Popup для расчёта по дате рождения.
- Ручной ввод с автоматическим форматированием даты.
- Расчёт по выделенной дате через контекстное меню.
- Возраст в годах и календарных компонентах.
- Знак зодиака.
- Паспортные контрольные даты для возрастов 14, 20 и 45 лет.
- 90-дневные календарные границы и следующий возрастной этап.
- Тёмная и светлая темы.

### Технически

- Manifest V3.
- Локальная обработка без сетевых запросов.
- Минимальные permissions: `contextMenus` и `storage`.
- Unit tests на встроенном Node.js test runner.
